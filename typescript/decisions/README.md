# Decisions

This directory records binding architecture and dependency decisions for TypeScript projects.

## Contents

- [architecture-decision-records.md](architecture-decision-records.md) defines when and how to record an ADR.
- [framework-selection.md](framework-selection.md) defines the default stack, alternatives, and approval questions.

## Recording A Decision

Use [templates/adr-template.md](../templates/adr-template.md). Record the decision before implementing a hard-to-reverse change, number it monotonically, and link superseded records rather than rewriting history.
