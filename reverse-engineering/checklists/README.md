# Checklists

Gates for the reverse-engineering handbook. Each checklist is a set of evidence-backed questions; any unchecked box stops the work it gates. The rules behind each box live in the linked topic docs.

- [engagement-intake.md](engagement-intake.md) — before any analysis on a new game or engagement: purpose, authorization, workspace, fingerprint, tooling. Re-run the Target group on every major patch.
- [runtime-session-gate.md](runtime-session-gate.md) — before any action that runs, attaches to, injects into, debugs, or intercepts the client or its traffic.
